
# Networking Practical Lab

## Objective
To understand basic Windows networking commands used in cybersecurity.

## Commands Practiced

### 1. ipconfig
Purpose: Displays IP configuration.

### 2. ping google.com
Purpose: Tests network connectivity.
Result: Received replies.

### 3. nslookup google.com
Purpose: Checks DNS resolution.

### 4. ipconfig /all
Purpose: Displays detailed network adapter information.

### 5. netstat -ano
Purpose: Displays network connections and process IDs.

## Windows Event Viewer
Learned about:
- System Logs
- Security Logs
- Application Logs
- Event IDs

## Learning Outcome
I learned basic networking commands, DNS,
network connections, and Windows event logs.
