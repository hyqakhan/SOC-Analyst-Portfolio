
# Networking Fundamentals

## 1. What is Networking?
Networking is the connection of two or more devices to share data and information.

## 2. What is an IP Address?
An IP address is a unique address used to identify a device on a network.

## 3. What is DNS?
DNS stands for Domain Name System. It translates domain names into IP addresses.

## 4. What is TCP?
TCP stands for Transmission Control Protocol. It provides reliable data communication.

## 5. What is UDP?
UDP stands for User Datagram Protocol. It sends data without establishing a connection.

## 6. What is a Port?
A port is a communication endpoint used by network applications.

## Learning Outcome
I learned the basic concepts of computer networking used in cybersecurity and SOC operations.
